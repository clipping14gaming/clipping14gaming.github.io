Règles de confidentialité – Clipping Gaming

Dernière mise à jour : 19 novembre 2026

Données utilisées

L'application demande une seule autorisation Google : youtube.upload. Elle sert uniquement à mettre en ligne des vidéos sur la chaîne YouTube du compte qui s'est connecté. L'application ne lit pas tes e-mails, tes contacts, tes fichiers ni d'autres données de ton compte Google.

Stockage

Le jeton d'accès fourni par Google est enregistré uniquement sur l'ordinateur où l'application est installée. Il n'est envoyé à aucun serveur tiers. Aucune donnée personnelle n'est vendue, partagée ou utilisée à des fins publicitaires.

Utilisation des données Google

L'utilisation des informations reçues des API Google respecte les règles concernant les données utilisateur des services API Google, y compris les exigences d'utilisation limitée. L'application utilise aussi les services API YouTube : voir les conditions d'utilisation de YouTube et les règles de confidentialité de Google.

Révoquer l'accès

Tu peux retirer l'accès à tout moment sur myaccount.google.com/permissions.
